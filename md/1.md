Key mismatches vs. typical XYW‑Net training/eval
- Loss/activation
  - Notebook: outputs already sigmoid + plain BCE.
  - Original practice: logits + class‑balanced BCE (or pos_weight) to handle heavy edge sparsity; sigmoid only at eval.
- Decoder blocks
  - Notebook: Refine_block2_1 uses Conv2d('2sd') directly.
  - Original: typically uses the gated adap_conv (learnable sigmoid weight) before upsample. You have adap_conv commented out.
- Input preprocessing
  - Notebook: no mean/std normalization.
  - Original: normalized RGB (usually ImageNet mean/std) and stronger data augmentation.
- Evaluation
  - Notebook: Canny as a thinning surrogate + 1‑px dilation for tolerance and a custom ODS/OIS sweep.
  - Original: PDollar/BSDS-style boundary evaluation (ximgproc.thinning or MATLAB scripts). Absolute numbers won’t match with Canny-thinning + simple dilation.
- Training schedule
  - Notebook: 3 epochs on 35/7 samples is far too short. Original models train longer on BIPED/BSDS with LR schedules and augmentations.
- API parity
  - forward_with_stages is missing from your active XYWNet (used later in visualize_stages).
- Minor
  - TracerWarning comes from a Python if in createPDCFunc; benign for now, but not ideal for TorchScript.
  - Your val set is test/; the original splits and image sizes may differ.

class EdgeLoss(nn.Module):
    """Class-balanced BCE on logits (handles edge sparsity)"""
    def __init__(self, eps=1e-6):
        super().__init__()
        self.eps = eps

    def forward(self, logits, label):
        y = label
        p = torch.sigmoid(logits).clamp(self.eps, 1 - self.eps)
        pos = (y > 0.5).float()
        neg = 1.0 - pos
        Np = pos.sum().clamp(min=1.0)
        Nn = neg.sum().clamp(min=1.0)
        beta = Nn / (Np + Nn)          # weight positives less when many negatives
        pos_loss = -beta * (pos * torch.log(p))
        neg_loss = -(1 - beta) * (neg * torch.log(1 - p))
        return (pos_loss + neg_loss).mean()

# ...existing code...
def nms_edge(pred):
    pred_blur = cv2.GaussianBlur(pred, (3,3), 0)
    pred_uint8 = (np.clip(pred_blur, 0, 1) * 255).astype(np.uint8)
    try:
        edges = cv2.ximgproc.thinning(pred_uint8, thinningType=cv2.ximgproc.THINNING_ZHANGSUEN)
    except Exception:
        edges = cv2.Canny(pred_uint8, 50, 150)
    return edges.astype(np.float32) / 255.0
